# Piarno (Keyboard-less Piano System)

単眼RGBカメラのみを用いて机面タップ（打鍵）を高精度かつ超低遅延で検出し、ブラウザ上でリアルタイムなピアノ演奏を実現するキーボードレス・ピアノ演奏システム。

---

## 概要

`Piarno` は、LiDARやToFなどの深度センサー、物理キーボード、ウェアラブルデバイスを一切使わず、**市販PC・スマートフォン・タブレットの内蔵単眼カメラ**と**Web標準技術（HTML5 Canvas / Web Audio API / MediaPipe / WASM / WebGL）**のみで構築されたリアルタイム演奏システムです。

机の上に端末を立てかけ、机面を指先でタップするだけで、手の動きを正確に捉えてピアノ音や母音発声を奏でることができます。

---

## 主な特徴・コア技術

### 1. 極小レイテンシ音響合成（Web Audio API）
- 外部オーディオファイル（mp3/wav等）を再生する際の読み込み遅延やデコードジッターを排除。
- Web Audio API のオシレーター加算合成（基音 Triangle波 ＋ 第2/第3倍音 Sine波 ＋ 80ms急減衰アタックエンベロープ）を採用し、打鍵が検出されたフレームと同一イベントループ内で即時発音します。

### 2. 幾何学的自己正規化モデル（Self-Normalizing Spatial Model）
- カメラとの距離（遠近）や手の大きさ（個人差）による座標変動を解消するため、手首から中指付け根までの3D距離を基準長 $L$ として算出。
- 指先の垂直位置を無次元化相対変位 $r_y = \Delta y / L$ として正規化することで、スケール不変な判定を実現しています。

### 3. 適応型信号平滑化（1 Euro Filter）
- 各指の関節座標に対して速度適応型ローパスフィルタ（1 Euro Filter）を適用。
- 静止・待機時の手ブレやジッターを強力に抑制しつつ、打鍵時の急激な下降（アタック）には遅延ゼロで追従します。

### 4. 右手追従セレクター ＆ 運指ガイドシステム
- 画面内に両手や第三者の手が映り込んでも、位置連続性とナックル外積により右手のみを安定追従。
- 画面上のミニマルピアノ鍵盤および右手運指ガイドウィジェットにより、次の打鍵対象（指番号・音名・色）をリアルタイムに視覚提示します。

### 5. カメラ同期パイプライン（requestVideoFrameCallback）
- ブラウザの描画ループだけでなく、カメラの物理フレーム到着に同期してMediaPipe推論を実行。
- 無駄な重複推論を省き、低負荷かつ安定したフレームレートを維持します。

## 必要環境とセットアップ

### 前提環境
- **Node.js**: v18.0.0 以上推奨
- **対応ブラウザ**: Chrome, Safari, Edge（カメラアクセス権限が必要です）

### 開発・起動手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（ローカル / LAN）
npm run dev

# 本番向けプロダクションビルド
npm run build
```

---

## 設置と操作方法

1. **端末の配置**:
   - iPhoneやiPad、ノートPCを机の上に立てかけ、手のひら全体が画面内に収まるように配置します。
2. **演奏開始**:
   - 画面の「スタート」ボタンをタップし、カメラとオーディオを有効化します。
3. **楽曲演奏**:
   - 運指ガイドウィジェットや鍵盤でハイライトされた指で机面をタップすると、メロディと自動伴奏が進行します。
   - 画面右上の「♪」ボタンから楽曲の切り替えが可能です。
